# Product Category Prediction

Ταξινόμηση προϊόντων σε 10 κατηγορίες από κείμενο, με κανόνα που στέλνει τα
αβέβαια σε ανθρώπινο έλεγχο.

**Το παραδοτέο είναι το [REPORT.md](REPORT.md).** Εκεί βρίσκονται τα
αποτελέσματα, οι αποφάσεις σχεδιασμού, τα πειράματα, η δομή του repository και
η χρήση του μοντέλου.

## Εγκατάσταση

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Kernel για τα notebooks: `product-cat (.venv)`.

Η σειρά εκτέλεσης των notebooks και των scripts είναι στην ενότητα
«Πού βρίσκεται το καθένα» του [REPORT.md](REPORT.md).
